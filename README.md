# DotNetScope — .NET Visual Lab

Interactive experiments that make real .NET runtime behavior visible.

## Lab 01 - Dependency Injection Lifetimes

Visualize how ASP.NET Core resolves:

- Transient services
- Scoped services
- Singleton services

The visualization is driven by real runtime service instances and GUIDs rather than simulated data.

## Goal

Learn .NET concepts by predicting behavior, executing real code, and visualizing what the runtime actually did.
